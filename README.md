#Vertical Jump Analyser (v0.1)
A simple Python tool to calculate vertical jump height and check dunk progress based on basic kinematic formulas.
##Features (v0.1)
-Takes hang time input to calculate vertical jump height.
-Calculates distance to target dunk height based on standing reach.
-Provides basic performance feedback.
##How to run
1.Open main.py in PyCharm.
2.Run the script and follow the terminal prompts.
